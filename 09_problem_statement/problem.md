
# Problem Statement & How Might We

## Problem Statement

Dóri needs a way to discover events that match her interests and find reliable event information,
because event details are often spread across different platforms.

Today she switches between Instagram, event websites and search engines to find and compare events,
which fails when important information is missing or booking links are difficult to find.

## Five How Might We Questions

**1. Speed**

How might we help Dóri discover interesting events faster without searching across multiple platforms?

**2. Trust**

How might we help Dóri trust event information without having to check several different websites?

**3. Cooperation**

How might we help Dóri discover and share events with friends without relying only on social media?

**4. Timing**

How might we help Dóri discover relevant events before they sell out or take place?

**5. Place**

How might we help Dóri find events in convenient locations without spending time searching different platforms?

## The One I Choose

How might we help Dóri find and trust relevant events without switching between multiple platforms?

**Why I chose this:**

All three participants described using multiple platforms to discover events and find information. P1 and P3 specifically experienced difficulty finding complete information in one place. This question addresses a recurring problem while leaving room for different design solutions.
